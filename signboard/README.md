# SignBoard: ระบบป้ายดิจิทัล (แนว Yodeck)

เว็บแอป fullstack สำหรับจัดการป้ายโฆษณาดิจิทัล: จับคู่จอ อัปโหลดสื่อ สร้างเพลย์ลิสต์ ตั้งตารางเวลา และหน้า Player ที่เปิดบนทีวีหรือคอมพิวเตอร์ได้เลย

## เริ่มใช้งาน

ต้องใช้ Node.js 22.5 ขึ้นไป (ใช้ SQLite ที่มากับ Node ไม่ต้องติดตั้งฐานข้อมูลเพิ่ม)

```bash
npm install
npm start            # http://localhost:3000
```

ลองพร้อมข้อมูลตัวอย่าง (ร้านกาแฟ 3 จอ รูป 6 ใบ เพลย์ลิสต์ 3 ชุด ตารางเวลา):

```bash
npm install
npm run demo         # เติมข้อมูลตัวอย่างแล้วเปิด http://localhost:3000
```

- หน้าจัดการ: `http://<เซิร์ฟเวอร์>:3000/` เข้าด้วย `admin` / `admin123` (เปลี่ยนได้ในเมนูตั้งค่า หรือกำหนดผ่าน `ADMIN_USER`, `ADMIN_PASSWORD` ก่อนรันครั้งแรก)
- หน้าจอแสดงผล: `http://<เซิร์ฟเวอร์>:3000/player` เปิดแบบเต็มจอ (F11 หรือโหมด kiosk ของ Chrome)

## ขั้นตอนการใช้งาน

1. เปิด `/player` บนจอ จะมีรหัส 6 ตัวขึ้นมา
2. ในหน้าจัดการ ไปที่ “จอแสดงผล” แล้วกด “เพิ่มจอ” กรอกรหัส
3. อัปโหลดรูป/วิดีโอใน “คลังสื่อ” (หรือเพิ่มเว็บเพจด้วย URL)
4. สร้างเพลย์ลิสต์ เพิ่มสื่อ ลากเรียงลำดับ ตั้งเวลาแสดงแต่ละชิ้น
5. ตั้งเพลย์ลิสต์หลักให้จอ หรือสร้าง “ตารางเวลา” ให้เล่นเพลย์ลิสต์ต่างกันตามวัน/ช่วงเวลา

จอจะดึงเนื้อหาใหม่ทุก 30 วินาที และเก็บเนื้อหาล่าสุดไว้ในเครื่อง ถ้าเน็ตหลุดก็ยังเล่นต่อได้ (มีจุดแดงมุมขวาล่างบอกสถานะออฟไลน์)

## ฟีเจอร์

- จับคู่จอด้วยรหัส, สถานะออนไลน์/ออฟไลน์, จอแนวตั้ง (หมุน 90°)
- คลังสื่อ: รูปภาพ, วิดีโอ (0 วินาที = เล่นจนจบ), เว็บเพจ; อัปโหลดแบบลากวางหลายไฟล์
- เพลย์ลิสต์: ลากเรียง, กำหนดเวลาแต่ละรายการ, เปลี่ยนภาพแบบเฟดหรือตัดทันที
- ตารางเวลา: เลือกวันในสัปดาห์, ช่วงเวลา (รองรับข้ามเที่ยงคืน), ช่วงวันที่, ลำดับความสำคัญ
- เวลาในตารางใช้เวลาท้องถิ่นของเครื่องที่เปิด Player

## โครงสร้าง

```
src/server.js     Express API + เสิร์ฟหน้าเว็บ
src/db.js         SQLite schema และบัญชีผู้ดูแล
src/seed.js       ข้อมูลตัวอย่าง (npm run demo)
public/           หน้าจัดการ (index.html, app.js) และ player.html
data/             ฐานข้อมูลและไฟล์ที่อัปโหลด (สร้างอัตโนมัติ, ตั้ง DATA_DIR เพื่อย้ายได้)
test/             ทดสอบ logic ตารางเวลา (npm test)
```

## ตัวแปรสภาพแวดล้อม

| ตัวแปร | ค่าเริ่มต้น |
|---|---|
| `PORT` | 3000 |
| `DATA_DIR` | `./data` |
| `ADMIN_USER` / `ADMIN_PASSWORD` | `admin` / `admin123` (ใช้ตอนสร้างฐานข้อมูลครั้งแรกเท่านั้น) |
